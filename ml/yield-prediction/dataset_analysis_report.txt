IMPORTANT MODELING NOTE
------------------------------------------------------------
Production must NOT be used as an input feature when predicting yield because yield is mathematically derived from production and area.
The first model should therefore avoid target leakage and use only information available before/at prediction time.
The next step will transform the wide crop columns into a clean long-format dataset with Year, State, District, Crop, Area and Yield.
